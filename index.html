Color Walter

Más difícil de lo que crees

Color Walter es un rompecabezas de orden de colores al estilo de las Torres de Hanói. Cada botella guarda capas de líquidos de colores mezclados.

  • Toca una botella pequeña para tomarla y luego una botella de destino.
  • Sólo se vierte el color de arriba, y sólo si el destino está vacío o tiene ese mismo color encima.
  • Las 2 botellas grandes no se pueden mover: sólo reciben líquido.
  • Cuando una botella se llena de un solo color, se le pone un tapón y queda sellada.
  • Ganas cuando todas las botellas quedan ordenadas. ¡Hazlo en la menor cantidad de movimientos!
